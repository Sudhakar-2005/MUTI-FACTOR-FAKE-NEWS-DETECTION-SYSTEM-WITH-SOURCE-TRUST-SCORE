Upload a CSV file to bulk-add domains with custom thresholds to your watchlist.

CSV Format

Each row should contain: domain,threshold

Example:

domain,threshold
example.com,10
suspicious-site.xyz,20
news-source.org,15

If threshold is omitted, the default (15) will be used. Header row is optional.
